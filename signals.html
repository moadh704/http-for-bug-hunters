Module 05

What to notice

You are not collecting payloads. You are collecting disagreements: two layers that do not share a definition of the request.

Who parsed it

A CDN, a load balancer, a language runtime, and the app can each decide where the body ends, which host is real, and whether the method is POST. Write the path of hops when you can. A bug that only reproduces through the public hostname, and not against the origin, belongs to the hop in between.

Content-Type is a claim about the body. Send the same bytes as JSON and as a form. If the app accepts both and applies different checks, you have found the check that only runs for one parser.

Trust boundaries in the header block

Anything the client can set is untrusted: Host overrides, forwarded headers, a URL in a query parameter that becomes a server-side fetch, a path that becomes a redirect. The bug is the server treating that value as its own idea.

A newline inside a header value is special because HTTP/1.1 headers are lines. If the server writes your input into a header and does not strip CR or LF, you may start a new header or even a new response. Test the encoding in a lab, and stop at the first unexpected header rather than building a full response.

A short loop that stays honest

Pick one request the app really makes. Change one thing. Compare status, length, and the headers that matter (Location, Set-Cookie, Access-Control-Allow-Origin, Cache-Control). Write the difference in one sentence. That sentence is the start of a report.

If you cannot say which header or which boundary changed, you do not have a finding yet. You have a hunch.

The practice page lists labs where this loop is allowed. The live internet is not your lab.

Check yourself

Three questions. Nothing unlocks. A pass is just a mark in this browser so you know you read it.

  1. A bug that only shows up through the CDN, not the origin, belongs to

    If origin and edge disagree, the rewrite between them is the system under test.

  2. Changing only Content-Type is a useful test when

    The bytes did not change. The claim about how to parse them did. Different claims often hit different code.

  3. A report-ready observation names

    One controlled change plus one observed difference is evidence. A hunch is not.
