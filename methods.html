Module 02

Methods

The verb is a promise about side effects. Broken access control often starts when the app believes the promise and an attacker does not.

What the verb claims

GET and HEAD are supposed to be safe: they should not change state. PUT and DELETE are supposed to be idempotent: repeating them has the same end state as doing them once. POST is neither. PATCH is a partial change and is not automatically idempotent.

Those are conventions, not laws. A GET that changes a password, or a POST that a cache stores, is a bug even if the status code is 200.

The interesting mismatches

Look for the same action on two verbs. A form posts to /user/delete, and GET /user/delete?id=4 does the same thing. That is request forgery waiting for a link. Look for method override headers (X-HTTP-Method-Override and friends) that retune a POST into a DELETE the edge never intended to allow.

A 405 is useful. It means the path exists and this verb is refused. Try the verb the app uses in the browser, then the one an admin API might use. Do not spray every verb at production hosts you are not authorized to test.

POST /api/users/4 HTTP/1.1
Host: app.example
X-HTTP-Method-Override: DELETE
Content-Length: 0

If the edge allows POST and the app honors the override, the block on DELETE never ran.

OPTIONS is a map

An OPTIONS response, especially a CORS preflight, lists methods and headers the server is willing to talk about. Treat Allow and Access-Control-Allow-Methods as a hint, then confirm with one request. Hints lie.

Check yourself

Three questions. Nothing unlocks. A pass is just a mark in this browser so you know you read it.

  1. A GET that changes server state is a problem because

    Safe methods get followed, prefetched, and stored. A state change on GET leaks into those behaviors.

  2. What is a 405 good for?

    405 Method Not Allowed means the server recognized the target and rejected the verb. 404 means it did not map the target.

  3. X-HTTP-Method-Override matters when

    The override is an application convention. The proxy and the app can disagree about which verb they enforced.
