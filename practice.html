Practice

This guide does not ship a vulnerable lab. The labs already exist. Use them, and keep notes in the shape of one change and one difference.

  • PortSwigger: HTTP request smuggling

    The cleanest place to see two parsers disagree about a boundary.

  • PortSwigger: Web cache poisoning

    Unkeyed headers and cache keys, with labs that reset.

  • PortSwigger: Host header attacks

    Password-reset links and routing that trust Host.

  • PortSwigger: CORS

    Reflected origins and credentialed reads.

  • MDN: HTTP overview

    The reference when a header name is unfamiliar. Spec language, not a lab.

Keep the note as one sentence: the field you changed, and the status or header that moved. If you cannot write that sentence, you are not done with the request.
